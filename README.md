# 서울도서관 리뉴얼 프로젝트 (Seoul Library Renewal)

서울도서관의 통합 검색 및 예약 서비스를 현대적인 감각으로 리뉴얼한 웹 어플리케이션입니다.

## ✨ 주요 기능
- **통합 검색**: 도서관 내 모든 자료를 빠르게 검색할 수 있습니다.
- **도서 예약**: 실시간으로 도서를 예약하고 상태를 확인할 수 있습니다.
- **현대적인 UI**: 반응형 디자인과 부드러운 애니메이션을 적용하여 프리미엄한 사용자 경험을 제공합니다.
- **다양한 정보 제공**: 도서관 소식, 시설 안내, 층별 안내도 등 직관적인 정보를 제공합니다.

## 🚀 시작하기

이 프로젝트는 Vite와 React를 사용하여 제작되었습니다.

### 사전 요구 사항
- [Node.js](https://nodejs.org/) (버전 18 이상 권장)

### 설치 및 실행
1. 저장소를 클론하거나 압축 파일을 해제합니다.
2. 터미널에서 해당 디렉토리로 이동합니다.
3. 의존성 패키지를 설치합니다:
   ```bash
   npm install
   ```
4. 로컬 개발 서버를 실행합니다:
   ```bash
   npm run dev
   ```
5. 브라우저에서 `http://localhost:5173` 접속하여 확인합니다.

## 🛠 사용된 기술
- **Frontend**: React, Vite
- **Styling**: CSS3 (Vanilla CSS)
- **Design Concepts**: Glassmorphism, Modern Minimalist
